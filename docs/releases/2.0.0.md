# qMusic 2.0.0

qMusic 2.0 正式版面向 Windows 发布，整合新版界面、桌面悬浮播放器、同步歌词、下载管理与离线播放。

## 更新内容

- 以 Apple Music 风格统一主页、侧栏、图标、字体和播放控件，保留媒体库、收藏、播放列表与聆听统计。
- 应用内播放条在各页面保持悬浮；长歌曲名与歌手名自动滚动，播放队列通过浮层打开。
- 新增独立置顶的桌面悬浮播放器，支持拖动、滚轮调节音量、展开同步歌词与播放队列，并保留窗口位置及面板状态。
- 改进全屏播放器的展开、收回与封面过渡，优化专辑封面比例和封面流动背景。
- 修复手动浏览歌词时的模糊显示，以及桌面悬浮歌词因额外轮询而延迟的问题；歌词偏移方向与主界面保持一致。
- 统一进度条拖动手柄，改进按钮焦点、点击反馈和悬浮播放条的交互。
- 保留下载管理、边听边存、本地音频优先播放和离线浏览。具体范围见[下载与离线说明](../OFFLINE.md)。
- 更新 README 与当前界面截图，补充桌面悬浮播放器说明。

## 安装与更新

- 提供 Windows x64 和 ARM64 的 EXE 安装程序及 ZIP 压缩包。
- x64 构建包含 MPV；ARM64 可使用内置播放器，或自行配置兼容的 MPV。
- 此版本为正式版，设为 GitHub 最新发布，提供 Stable 通道的自动更新元数据。
- 如此前选择了 Beta 更新通道，可在高级设置中切换到 Latest（最新的），以继续接收正式版更新。
- 升级沿用已有服务器配置、播放设置、缓存与下载记录。默认下载目录仍为系统音乐文件夹下的 `Feishin` 目录。
- 本次不提供 macOS 和 Linux 安装包，可按仓库说明从源码构建。
- 附件中的 MPV `.7z` 是经 SHA-256 校验的原始构建依赖镜像，普通用户无需单独下载或安装；x64 安装程序及 ZIP 已包含 MPV。
