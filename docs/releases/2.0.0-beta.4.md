# qMusic 2.0.0-beta.4

本次 Beta 将软件更名为 **qMusic**，项目介绍使用 **qMusic for Windows**。

## 更新内容

- 更新窗口标题、侧栏、托盘菜单、安装包、快捷方式和多语言文案中的软件名称。
- 同步更新远程控制页面、网页版应用名称，以及向音乐服务器报告的客户端名称。
- 保留原有配置目录、缓存标识和下载目录，升级后继续使用已有服务器配置、播放设置及离线记录。
- 调整横屏全屏播放器中的封面位置。

## 安装与更新

- Windows 提供安装程序及 ZIP 压缩包；x64 构建包含 MPV，ARM64 可使用内置播放器或自行配置兼容的 MPV。
- macOS 和 Linux 安装包同样由本次 GitHub Actions 工作流构建。
- 如需自动接收预发布更新，请在高级设置中将更新通道设为 Beta。
- 本版本是预发布版本。已有下载仍保存在系统音乐文件夹下的 `Feishin` 目录，配置目录也沿用旧名称。
