# Feishin 1.16.0

本次大版本更新重点改进全屏播放体验、歌词交互和 Windows 媒体控制。

## 全屏播放器

- 专辑封面取色的柔和流动背景，结合可用的音频波形轻微律动；暂停音乐时停止动画。
- 使用低分辨率画布和受限帧率，降低动态背景的 GPU 开销。
- 统一白色文字和图标，未开启的功能使用灰色；底部控制栏融入背景。
- 隐藏重复的小封面和歌曲信息，调整大封面位置，点击封面可退出全屏播放页。
- 增加右上角窗口控制，右侧辅助按钮按需显示；鼠标点击后移开即可隐藏，保留键盘操作支持。
- 播放队列仅保留序号、歌曲信息和时长，布局更紧凑，打开更快。

## 歌词与媒体库

- 手动浏览歌词时不再被播放进度抢回位置，鼠标离开一秒后恢复跟随。
- 已播放和未播放的歌词增加轻微模糊，当前歌词保持清晰。
- 全屏歌词区隐藏额外的匹配曲目标题，减少重复信息。
- 修复歌名滚动未随容器和字体尺寸更新的问题，及时清理已结束的动画。
- 修复部分歌曲有年份却不显示的问题，发行年份缺失时使用歌曲年份。
- 左侧栏播放列表顺序与媒体库排序保持一致，保留手动排序方式。
- 移除侧栏底部重复的媒体库标识和全屏“相关”入口。

## Windows 与播放稳定性

- 修复 Windows 媒体面板显示“未知应用”的问题，安装时注册 Feishin 名称和图标。
- 修复系统媒体面板暂停后，播放器按钮状态不同步的问题。
- 修复任务栏缩略图控制按钮消失，播放和暂停图标跟随实际状态更新。
- 移除任务栏标题中的播放队列计数。
- 完善 MPV 播放状态与队列切换的同步处理。

安装包和便携版由 GitHub Actions 构建，现有设置和媒体库配置继续保留。
