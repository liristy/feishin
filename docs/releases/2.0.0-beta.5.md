# qMusic 2.0.0-beta.5

本次更新重塑主界面，以 Apple Music 风格统一侧栏、悬浮播放条、图标和全屏播放器，保留原有首页内容及音乐库功能。

## 更新内容

- 重新设计首页与本周排行榜，统一页面间距、字体、配色和导航。聆听统计移到主页下方。
- 更新侧栏标识和图标，修正收藏、搜索的对齐以及播放列表滚动。搜索在侧栏向上滚动时显示，并保留操作时间。
- 加大悬浮播放条，统一歌曲信息字号，修正进度条显示。播放、上一首、下一首和音量控制增加动画。
- 播放队列改为悬浮面板；全屏歌词页内沿用原有队列切换方式。精简更多操作与音量弹出面板。
- 全屏播放器从播放条展开并收回，改进封面清晰度、动画衔接及关闭后的播放条显示。恢复右上角窗口控件自动隐藏，并上移播放控制和进度条。
- 更新歌词、播放列表、收藏和自动 DJ 图标。移除歌词页导出与搜索入口，缩小歌词偏移控件。
- 重写 README，并替换为新版界面截图。

## 安装与更新

- 本次仅发布 Windows 安装程序与 ZIP 压缩包，提供 x64 和 ARM64 架构。
- x64 构建包含 MPV；ARM64 可使用内置播放器，或自行配置兼容的 MPV。
- 如需自动接收预发布更新，请在高级设置中将更新通道设为 Beta。
- 升级沿用已有服务器配置、播放设置、缓存与下载记录。默认下载目录仍为系统音乐文件夹下的 `Feishin` 目录。
