# 下载管理

桌面端侧边栏的“下载管理”页面使用音乐库一致的标题栏、搜索和歌曲列表，分为“已下载 / 下载任务”。边听边存与下载目录位于右上角下载设置中。

- 保存的登录信息直接使用，启动和切换服务器不再预先验证连接。已登录的服务器在断网时仍可进入应用。曾浏览的列表、详情和图片保存在 IndexedDB，歌曲播放不依赖再次向服务器获取播放地址。
- 右键歌曲、专辑、歌手、文件夹或歌单，选择下载。歌曲逐首下载为原始音频，默认保存到系统音乐目录的 `Feishin/<媒体库相对路径>`，保留服务器的子目录和文件名，Navidrome 的 `.strm` 条目保存为实际音频格式。没有相对路径的旧数据按歌手和专辑整理，同名冲突增加歌曲标识，不覆盖其他文件。可以用 Feishin 或其他支持该音频格式的播放器打开。
- “边听边存”默认开启。播放过程中通过独立请求下载原始音频，会增加网络流量。保存位置和手动下载相同，完整保存后直接归入“已下载”，无需再次点击下载。未完成的音频不能离线播放。
- 所有音频统一保存在音乐目录，不设缓存容量或自动清理。旧版歌曲缓存和扁平下载目录启动时自动迁移到新的目录结构，无须联网或重新下载；迁移失败保留原文件，可在任务中重试或下次启动时再次迁移。
- 下载最多同时执行两个任务，支持查看进度、取消和失败重试。网络中断导致下载失败后可以手动重试。退出应用时未完成的任务需要重新发起。
- 可在下载管理中搜索、播放全部、单曲播放、删除本地文件、右键定位已下载文件以及打开音乐文件夹。已保存的文件和索引跨重启保留；手动移走或删除的文件会从索引中剔除。

断网时自动读取已有的缓存，不需要切换模式。没有完全匹配的页面快照时，使用该服务器和账号下已保存的记录及已下载歌曲，支持本地分页、排序、常用筛选、搜索和详情浏览。这里仅包含本地已有内容，不能还原未保存的完整服务器媒体库；不支持在本地执行自定义服务器筛选表达式。未完整保存的歌曲仍需联网播放。服务器不可达时，已有快照最多等待 350 毫秒即显示；请求在 4 秒后中止，随后 30 秒直接使用本地内容，网络恢复事件会清除等待状态。封面在浏览时缓存，下载歌曲时还会预取当前配置中的封面尺寸。缓存过的图片立即显示，联网且超过一天后在后台更新。侧栏和播放器大图也读缓存，缺少当前分辨率时复用同一封面的已有尺寸。

MPV 和内置播放器优先使用本地歌曲。内置播放器能否解码原始音频取决于 Chromium 支持的格式，特殊格式可使用 MPV。DLNA、服务器点唱机和网络电台仍需要网络。离线时不提交播放记录、不自动保存服务器队列，也不执行自动 DJ；离线播放记录不会在恢复联网后补传。

网页版支持已访问数据和图片的持久缓存，本地音频下载与音乐目录管理仅在桌面端提供。

## 验证

```sh
node scripts/tests/unit/test-offline.cjs
node node_modules/electron/cli.js scripts/tests/electron/test-offline-electron.cjs
pnpm build:electron
pnpm build:web
```

第一个检查覆盖文件校验、取消、旧缓存迁移、迁移失败保留源文件、重复下载合并、重启索引、服务器隔离、字节范围、接口与封面缓存。第二个检查使用隔离的临时用户目录与音乐目录，在真实 Electron 中下载音频、关闭测试服务器，然后通过本地协议播放和跳转进度。
