# PingFang SC

The bundled fonts come from
[zongren/font](https://github.com/zongren/font/tree/f73a1000d623a3570a2cd9cfbe4c31f0d1a43d2f)
at commit `f73a1000d623a3570a2cd9cfbe4c31f0d1a43d2f`, downloaded on 2026-09-19.

`PingFang-SC-Regular.ttf` is Regular (400). The source file named
`PingFang-SC-Bold.ttf` identifies itself as `PingFangSC-Medium` (500), so it is
bundled as Medium. Both TTF files are unchanged. The CSS family alias is
`Feishin PingFang`.
